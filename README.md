# 鼠标轨迹应用

这是一个使用 Electron 开发的全局鼠标轨迹应用程序。

## 功能特点

- 在屏幕上显示鼠标移动轨迹
- 可自定义轨迹长度、大小、透明度和颜色
- 支持多种轨迹类型（圆形、方形、星形、心形）
- 系统托盘集成，方便快速访问

## 安装和运行

### 安装依赖

```bash
npm install
```

### 运行应用

```bash
npm start
```

## 文件结构

- `main.js`: 主进程代码，负责创建窗口和系统托盘
- `index.html`: 主窗口界面
- `trail.html`: 轨迹设置窗口界面
- `icon.svg`: 应用图标
- `package.json`: 项目配置和依赖

## 使用说明

1. 运行应用后，系统托盘会显示一个绿色的图标
2. 双击托盘图标或在右键菜单中选择"显示主窗口"打开主界面
3. 可以通过主界面或轨迹设置界面调整轨迹参数
4. 应用程序默认最小化到系统托盘，不会显示在任务栏中

## 构建应用

### 构建 Windows 版本

```bash
npm run build
```
